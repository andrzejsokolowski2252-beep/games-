# games-

## Brain Break

`index.html` is a self-contained page with two quick brain games:

- **Sequence Memory**: watch the colored pads light up, then repeat the sequence. Each round adds a step.
- **Reaction Time**: wait for green, then click as fast as you can.

Best scores are saved in your browser's `localStorage`.

Open `index.html` in any modern browser to play. No build step needed.
